লজিস্টিক রিগ্রেশন প্যারামিটার আপডেট — এক্সাম সলিউশন

Question (English)
Consider the following dataset consisting of customer attributes and a purchase decision:
Customer ID Gender Income Category Children Purchase (Y)
C1 Male Low 0 No
C2 Female High 2 Yes
C3 Female Medium 1 Yes

Preprocessing: Encode categorical features (One-Hot Encoding for Gender, Label Encoding for Income Category where Low=0, Medium=1, High=2, and Target No=0, Yes=1). Explain why Min-Max normalization is required if numerical features have different scales.

Prediction: Given the initial weights β0 = -0.5, βMale = 0.2, βFemale = -0.1, βIncome = 0.4, compute the hypothesis h(x) = 1 / (1 + e-z) for the 3 samples. Using a decision threshold of 0.5, predict their class labels.

Parameter Update: Perform one step of Mini-Batch Gradient Descent with learning rate α = 0.1 to update the bias term β0.

ধাপ ১: প্রি-প্রসেসিং এবং ফিচার এনকোডিং (Preprocessing & Encoding)

নরমালাইজেশনের প্রয়োজনীয়তা (Min-Max Scaling):
যখন বিভিন্ন ফিচারের স্কেল বা পরিমাপের একক আলাদা হয়, তখন বড় মানের ফিচারগুলো গ্রেডিয়েন্ট আপডেট এবং ক্যালকুলেশনকে একতরফাভাবে প্রভাবিত করে। Min-Max Scaling ডেটাকে [0, 1] রেঞ্জে নিয়ে আসে, যার ফলে প্রতিটি ফিচার মডেলে সমপরিমাণ গুরুত্ব পায়।

এনকোডেড ডেটাসেট:
Sample xMale xFemale xIncome Target (y)
C1 1 0 0 0
C2 0 1 2 1
C3 0 1 1 1
ধাপ ২: লিনিয়ার কম্বিনেশন এবং প্রেডিকশন (Hypothesis & Prediction)
লিনিয়ার সমীকরণ: z = β0 + βMalexMale + βFemalexFemale + βIncomexIncome
সিগময়েড ফাংশন: h(x) = 1 / (1 + e-z)
নমুনা C1 এর জন্য:
z1 = -0.5 + (0.2)(1) + (-0.1)(0) + (0.4)(0) = -0.3
h(x1) = 1 / (1 + e0.3) = 1 / (1 + 1.3499) ≈ 0.426
যেহেতু 0.426 < 0.5 ⇒ প্রেডিক্টেড ক্লাস: 0 (No)
নমুনা C2 এর জন্য:
z2 = -0.5 + (0.2)(0) + (-0.1)(1) + (0.4)(2) = -0.5 - 0.1 + 0.8 = 0.2
h(x2) = 1 / (1 + e-0.2) = 1 / (1 + 0.8187) ≈ 0.550
যেহেতু 0.550 ≥ 0.5 ⇒ প্রেডিক্টেড ক্লাস: 1 (Yes)
নমুনা C3 এর জন্য:
z3 = -0.5 + (0.2)(0) + (-0.1)(1) + (0.4)(1) = -0.5 - 0.1 + 0.4 = -0.2
h(x3) = 1 / (1 + e0.2) = 1 / (1 + 1.2214) ≈ 0.450
যেহেতু 0.450 < 0.5 ⇒ প্রেডিক্টেড ক্লাস: 0 (No)
ধাপ ৩: বাযাস (β0) প্যারামিটার আপডেট (Gradient Descent)
গড় ত্রুটি (Average Error): Δβ0 = (1/m) ∑ (y(i) - h(x(i)))
আপডেট সূত্র: β0(new) = β0(old) + α × Δβ0

সাব-স্টেপ ১: গড় ত্রুটি হিসাব (Δβ0) [এখানে m = 3]:

Δβ0 = (1/3) × [ (0 - 0.426) + (1 - 0.550) + (1 - 0.450) ]
Δβ0 = (1/3) × [ -0.426 + 0.450 + 0.550 ]
Δβ0 = 0.574 / 3 ≈ 0.1913

সাব-স্টেপ ২: বাযাস (β0) আপডেট করা: [যেখানে α = 0.1]

β0(new) = -0.5 + (0.1 × 0.1913)
β0(new) = -0.5 + 0.01913 = -0.4809
চূড়ান্ত ফলাফল: নতুন বাযাস মান β0(new) = -0.4809
